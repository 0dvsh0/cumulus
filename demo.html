1. The Problem

Modern websites break for autonomous agents (ChatGPT, Claude, shopping bots) due to client-side hydration, blocked robots directives, missing schema, and uncrawlable checkout links.

2. What Cumulus Does

Evaluates any public website without an account across 4 categories: Discovery, Access, Usability, and Payments. Combines static inspection with real headless Chromium journey testing.

3. Actionable Remediation

Produces evidence-backed findings with concrete impact, step-by-step fixes, acceptance criteria, and a downloadable ZIP Fix Kit with Markdown remediation files.

4. Programmatic & Agentic

Documented check catalogue (/docs), REST API (/api/v1), and native Model Context Protocol (MCP) server for autonomous agents to audit sites automatically.
